Build **one** app end to end and learn the whole Vercel AI stack. You start by typing a sentence into v0 and finish with a multi-tenant, agentic, evaluated application running in production. Every level builds on the same app, every step is copy-pasteable, and every level ends with a check so you know it worked before moving on.

> **Heads up — this is an optional deep dive**
> This lab goes far beyond what you need for the two-week hackathon. The event is part-time, and you only need to ship ~25% of one idea — **no runtime AI is required**. Treat this as a "keep going after the event" track for anyone who wants the full picture. Skim the parts you need; ignore the rest.

> **Updated for AI SDK v7**
> The code here targets **AI SDK v7**, the current release. If you paste snippets from older blog posts you will hit renamed APIs — the callouts flag the ones that moved.

## Who this is for

Engineers who can already ship a Next.js app and want to know where the leverage actually is. Levels 0–2 are deliberately brisk — skim them if you already deploy on Vercel. **The compounding starts at level 3**, and levels 8–14 are where most teams leave quality on the table. Every level ends with primary-source references, because the ecosystem moved fast enough that half the blog posts you'll find are wrong.

Roughly 9 hours total: 4 beginner levels, 4 intermediate, 7 advanced.
