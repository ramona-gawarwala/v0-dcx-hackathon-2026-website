## Common issues

| Problem | Fix |
|---|---|
| App won't deploy | Check the Vercel build logs; fix the first error shown. |
| AI calls fail | Confirm your API key / AI Gateway is set in env vars. |
| Local `pnpm dev` errors | Run `pnpm install` again; check you're on Node 20+. |
| Env vars not working | File must be `.env.local`; restart the dev server. |
